Where should the error path live?

Same agent, same failure handling — drawn two ways. Both use a bigger flow than the happy-path demo, so you can see how each behaves as a flow grows.

Option 1 — catch-all under the flow

One handler below everything, with a dashed edge from each step that can fail.

Option 2 — branch off the agent

Sits beside the triggers, as a property of the agent rather than of the flow.
